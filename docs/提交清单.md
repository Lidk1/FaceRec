## 三、功能实现对照（需求 → 代码）

| 需求 | 实现位置 | 验收方式 |
| --- | --- | --- |
| FR-01 注册与身份录入 | `api.enroll`、`service.enroll` | Web `/enroll`、`POST /api/face/enroll` |
| FR-02 采集与 512 维特征提取 | `detector.py`、`encoder.py` | 注册返回 `samples/avg_quality`；`/api/face/status` 显示 `feature_dim=512` |
| FR-04 动态刷脸核验（多人拒绝） | `engine.recognize`、`detector.select_main_face` | 终端实时识别；多人画面返回 `result_type=3` |
| FR-09 特征库管理 | `api` 用户/特征接口、`/library` 页面 | 查看、删除特征、注销用户 |
| FR-12 模型效果监测 | `fr_recognize_log`、`stats` | 成功率、失败原因分布、平均耗时 |
| SYS-07 人脸隐私 | `cipher.py` | 库中仅密文；接口不返回密文；不存原图 |
| CSCI-FUN-01/02 识别能力 | `engine.py` | `pytest tests/test_engine.py`（20 例） |

## 四、质量证据

| 项 | 结果 |
| --- | --- |
| 单元测试 | `143 passed in 4.68s`（`pytest -q`） |
| 真实模型回测（未参与注册的照片） | 韩萧 0.943、朱佳豪 0.783/0.935 → 均识别成功 |
| 陌生人识别 | 最高相似度 0.006 → 判定相似度不足 |
| 异人最高相似度 | 0.572（阈值 0.70，留 0.13 余量） |
| 接口耗时（预热后） | 48~85ms（检测 + 推理 + 17 条特征比对） |
| 冷启动 | 模型加载约 1.5s（启动时预热） |
| 演示库 | 6 位用户 / 17 条加密特征 |

## 五、快速验收

```powershell
cd FaceRec
python scripts/seed_demo.py --force
python run.py --check
python run.py                 # http://127.0.0.1:8080/

# 可执行产物
cd dist\FaceRec
.\FaceRec.exe --check
.\FaceRec.exe
```

演示步骤见《启动说明》第四节（3 分钟演示脚本）。
