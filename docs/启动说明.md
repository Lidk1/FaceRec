# 启动说明

本系统提供两种启动方式：**源码启动**（开发/答辩演示，推荐）与**可执行产物启动**（免 Python 环境）。

---

## 一、可执行产物启动（推荐给验收老师）

产物目录（随提交的压缩包解压后）：

```
FaceRec-1.0.0-win64/
├─ FaceRec.exe          # 双击启动（控制台窗口保持运行）
├─ start.bat            # 等价入口：FaceRec.exe --no-browser
├─ _internal/           # 依赖、模型与前端资源（PyInstaller 打包，勿单独移动）
│  ├─ model/facenet2rec-inference.pb   # 512 维人脸模型（约 90MB）
│  └─ web/                             # 前端页面
├─ data/                # 预置演示库（6 位用户 / 17 条加密特征）
├─ logs/                # 运行日志（首次启动创建）
└─ 启动说明.txt
```

1. 双击 `FaceRec.exe`（或在命令行执行 `FaceRec.exe --no-browser`）；
2. 看到如下输出即启动成功：

```
==================================================================
 FaceNet2Rec 校园人脸识别系统  v1.0.0
 模型: facenet2rec-inference   就绪: True
 模型文件: ...\_internal\model\facenet2rec-inference.pb
 阈值: 0.7   特征库: 6 人 / 17 条特征
 访问: http://127.0.0.1:8080/
==================================================================
模型预热: {'warmed': True, ...}  耗时 1580ms
```

3. 浏览器访问 <http://127.0.0.1:8080/>（Chrome/Edge，首次需允许摄像头）；
4. 页面：`/` 识别终端、`/enroll` 人脸注册、`/library` 特征库；
5. 演示数据：**包内已预置** 6 位演示用户（韩萧、井泉清、王琳博、李定坤、梁爽、朱佳豪）；
   删除 `data/facerec.db` 可恢复为空白库；
6. 停止：关闭控制台窗口，或 `Ctrl + C`。

常用参数：

| 参数 | 说明 |
| --- | --- |
| `--port 8090` | 换端口（被占用时） |
| `--no-browser` | 不自动打开浏览器 |
| `--no-warmup` | 跳过模型预热（首帧会慢约 1.5s） |
| `--check` | 只做部署自检后退出 |

> 若 Windows 提示"未知发布者"：右键 exe → 属性 → 解除锁定，或选择"仍要运行"。
> 产物未做代码签名，仅用于课程演示。

## 二、源码启动

前置：Windows 10/11、Python 3.9.x、约 300MB 磁盘空间。

```powershell
cd FaceRec

# 1) 创建虚拟环境并安装依赖
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt

# 2) 准备模型（仓库不含权重）
#    将 20180402-114759.pb 放入 model/，然后裁剪为纯推理图：
python scripts/prune_graph.py model\20180402-114759.pb model\facenet2rec-inference.pb

# 3) 初始化演示数据（可选，用于答辩演示）
python scripts/seed_demo.py --force

# 4) 自检并启动
python run.py --check
python run.py
```

自检输出 `自检通过：模型、数据库、加密组件均已就绪。` 即可启动。

验证接口：

```powershell
curl http://127.0.0.1:8080/api/face/status
python -m facerec.cli recognize --image facenet_facerecognition\test_img\hanxiao_01.jpg
```

> 源码目录与模型文件路径请避免中文：OpenCV 的窄字符接口在部分场景下无法打开中文路径，
> 程序已对级联模型做临时目录适配，但将工程放在纯英文路径最稳妥。

## 三、运行配置

通过环境变量覆盖（无需改代码）：

```powershell
$env:FACE_THRESHOLD = "0.70"      # 相似度阈值
$env:FACE_WEB_PORT  = "8080"      # 端口
$env:FACE_AES_KEY   = "..."       # Base64 编码的 32 字节密钥（生产必改）
$env:FACE_DB_PATH   = "D:\data\facerec.db"
python run.py
```

完整配置表见《开发技术文档》第 10 章。

## 四、验收演示脚本（约 3 分钟）

1. 打开 `http://127.0.0.1:8080/`，允许摄像头；
2. 点击「开始识别」，将已注册同学的照片（`facenet_facerecognition/test_img/hanxiao_01.jpg`）
   正对摄像头 → 显示"韩萧 识别成功"、相似度约 0.94、耗时 <100ms；
3. 换一张未注册照片（`emb_img/other_01.jpg`）→ 提示"相似度不足"并给出刷卡降级提示；
4. 打开 `/enroll`，填写新学号/姓名，采集 3 帧 → 提交注册，右侧显示入库样本数与质量分；
5. 回到 `/library`，查看用户特征数、识别记录、成功率与失败原因分布；
6. 对某用户点击「删特征」，再刷脸 → 提示特征库为空，验证特征删除生效。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 端口占用 | `FaceRec.exe --port 8090` |
| 摄像头无画面 | 用 localhost 访问、允许浏览器权限、关闭占用摄像头的软件 |
| 提示模型未就绪 | 确认 `model/facenet2rec-inference.pb` 存在；源码方式需先执行裁剪脚本 |
| 控制台中文乱码 | `chcp 65001`，或设置 `PYTHONIOENCODING=utf-8` |
| 首次识别较慢 | 启动预热约 1.5s；若使用 `--no-warmup`，首帧包含加载耗时 |
| 杀毒软件拦截 exe | 加入信任区（PyInstaller 打包产物常见误报） |

更多排查见《开发技术文档》第 11 章。
